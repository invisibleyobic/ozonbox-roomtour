## Где живут значения

- Цвета, шрифты, радиусы, тени - **`app/globals.css`, блок `:root`**. Здесь их не дублируем.
- Тексты сезона - `lib/season/autumn.ts` (конфиг, не код экрана).
- Цены, названия товаров - база, показываются через `lib/catalog/format.ts`.
