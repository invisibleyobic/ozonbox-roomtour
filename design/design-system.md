# Дизайн-система OzoneBox

Закон для любого внешнего вида сайта. Читается перед любой работой с интерфейсом (маршрут - в `CLAUDE.md`, раздел «Дизайн»). Коротко, без «можно так, а можно так».

**Источник значений - `app/globals.css`, блок `:root`.** Этот файл описывает роли и правила, а не дублирует цвета: когда значение меняется, правится один блок `:root`, а здесь - только смысл.

**Откуда взято:** согласованный макет `mockups/v1-scenariy-1/index.html`, прототип каталога `prototypes/2026-09-09-katalog/css/catalog.css` и фирменная упаковка (`Озон Упаковка/`: белый флакон с голубой крышкой и знак O3). Всё три сходятся в одном направлении - чистый светлый интерфейс, один синий акцент, шрифт Manrope. Оливково-бумажный вариант из папки «Озон дизайн тест» в эту систему **не входит** (см. `refs/analysis.md`).

## 1. Палитра ролями

| Роль | Переменная | Значение | Где |
|---|---|---|---|
| Фон страницы | `--bg` | `#f4f7fb` | подложка всего сайта |
| Фон глубже | `--bg-deep` | `#eaf0f8` | секции-разделители |
| Поверхность | `--card` | `#ffffff` | карточки, панели |
| Линия | `--line` / `--line-soft` | `rgba(13,27,46,.08)` / `.05` | рамки, разделители |
| Текст основной | `--ink` | `#0d1b2e` | заголовки, цены |
| Текст приглушённый | `--ink-soft` | `#5a6b83` | описания |
| Текст слабый | `--ink-mute` | `#8a99ad` | подписи, артикул |
| **Акцент (один)** | `--brand` | `#3c6df0` | главная кнопка, ссылки, фокус |
| Акцент при нажатии | `--brand-deep` | `#2b52c4` | нажатая и наведённая кнопка |
| Успех | `--ok` / `--ok-bg` | `#0e8f7e` / `#e3f6f3` | оплата прошла, промокод применён |
| Ошибка | `--err` / `--err-bg` | `#d7433a` / `#fdecea` | неверный код, сбой |
| Бирюзовая точка | `--aqua` | `#12b5a6` | только мелкие метки «новинка» и маркеры; кнопкой не бывает |

Осенняя сцена (`.scene-bg`, листья) использует тёплые янтарные и коричневые цвета - это сезонный конфиг, а не часть палитры сайта. Когда сезон меняется, меняется сцена, палитра сайта остаётся.

**Расхождение, найденное 21.09.2026:** в `app/globals.css` из этого списка сейчас есть только `--ink`, `--ink-soft`, `--ink-mute`, `--bg`, `--card`, `--line`, `--brand`, `--radius`. Остальное (`--brand-deep`, `--ok`, `--err`, тени, `--bg-deep`) нужно перенести из макета, когда появятся кнопки и формы. Это задача шага «применить систему к коду», а не переделка документа.

## 2. Шрифты

- Одна пара на весь сайт: **Manrope** для заголовков и текста. Один шрифт, разные начертания (400, 600, 700). Цены и цифры - тот же Manrope с `font-variant-numeric: tabular-nums`.
- Моно-шрифт (`ui-monospace`) - только для промокодов и артикулов.
- Подключается через `next/font/google` (локальная выдача, без запроса к Google при открытии страницы - это и скорость, и 152-ФЗ). Сегодня в коде стоит `system-ui`: это расхождение с макетом, исправляется первым при применении системы.
- Шкала: 12 / 14 / 16 / 20 / 26 / 42 px. **Текст для чтения не меньше 16 px**, мелкий (12-14 px) только для подписи, артикула и бейджа.

## 3. Геометрия

- Скругление: карточки и панели `--radius: 20px`; кнопки и поля 12px; бейджи 100px. Сегодня в коде `16px` - привести к 20px.
- Тень в покое: `--shadow-rest`. При наведении на карточку: `--shadow-lift`. Других теней нет.
- Линия: 1px, `--line`.
- Шаг отступов: 4px (4 / 8 / 12 / 16 / 24 / 40 / 60).
- Зона нажатия любой кнопки и ссылки-кнопки: **не меньше 44 x 44 px**.

## 4. Компоненты

| Компонент | Покой | Наведение | Нажатие | Заблокирована |
|---|---|---|---|---|
| Кнопка главная | фон `--brand`, текст белый, радиус 12px, высота 48px | фон `--brand-deep`, поднимается на 1px | фон `--brand-deep`, без подъёма | фон `--ink-mute`, курсор `not-allowed` |
| Кнопка вторая | фон белый, рамка `--line`, текст `--ink` | рамка `--brand` | фон `--bg-deep` | как главная |
| Поле формы | белый, рамка `--line`, высота 48px | рамка `--ink-mute` | рамка `--brand` + кольцо фокуса 3px `rgba(60,109,240,.25)` | фон `--bg` |
| Карточка товара | белая, рамка `--line`, `--shadow-rest` | `--shadow-lift`, фото увеличивается на 3% | - | - |
| Бейдж | фон `--ink`, текст белый, 11px, 100px | - | - | - |

У каждого элемента, на который можно нажать, виден фокус с клавиатуры (кольцо `--brand`), не только при наведении мышью.

## 5. Анимации

- Не больше 2-3 на экран. Сегодня на главной: появление карточек сцены при прокрутке и (когда будет видео) скраббинг сцены. Третье место оставляем свободным.
- Длительность 0.3-0.5 с, кривая `--ease-out: cubic-bezier(.16,1,.3,1)`.
- Анимация - украшение поверх уже читаемой страницы: если JavaScript не выполнился, всё видно (правило 3 из `architecture/00-правила-проекта.md`).
- Уважаем `prefers-reduced-motion: reduce`: без скраббинга и без сдвигов, только мгновенное появление. **Сегодня в коде этого нет** - записано в `check-glavnaya.md`.

## 6. ЗАПРЕЩЕНО

Каждый пункт - с причиной, чтобы не вернуть «потому что красиво».

1. **Текст внутри видео и картинки.** Заголовки, цены и кнопки только HTML поверх (принцип 10 в `CLAUDE.md`, правило 3). Причина: надпись в видео нельзя править, индексировать и читать без видео.
2. **Медицинские обещания и «лечит» в любом тексте интерфейса**, а также зачёркнутые «старые» цены. Причина: закон о рекламе и `architecture/00-правила-проекта.md` («Запрещено»).
3. **Второй акцентный цвет.** Акцент один, `--brand`. Бирюза `--aqua` - только точки-метки. Причина: два акцента размывают главную кнопку.
4. **Фиолетово-синие градиенты и «стеклянные» плашки как основной приём.** Причина: это дефолтный вид ИИ-сайтов, он делает магазин неотличимым. `--new: #7b4dff` из макета - это пометка «предложение» внутри макета, на сайт не переносится.
5. **Эмодзи вместо иконок.** Причина: разный вид на разных телефонах. Иконки - линейные, одним стилем.
6. **Третий шрифт.** Причина: лишний вес страницы и бюджет скорости LCP 2,5 с.
7. **Стоковые фото.** Причина: доверие. Только настоящая упаковка (пакшот) и наши сцены. Упаковку нейросеть не рисует - надписи на этикетке искажаются (правило из ТЗ на карточки Ozon, `Озон Раф md/README.md`, раздел 1).
8. **Цена, число или название сезона, вписанные в код экрана.** Причина: правило 2, цены живут в базе. Проверяет линтер (`eslint.config.mjs`).
9. **Всплывающие окна, которые закрывают экран до первого действия.** Причина: первый экран держит одно обещание и одну кнопку.
