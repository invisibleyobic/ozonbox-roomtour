# Памятка для параллельной сессии «Осенняя коробка»

Вставь этот текст в начало чата той сессии, которая делает осеннюю коробку.

---

Мы работаем параллельно с другой сессией Claude, которая делает главную OzoneBox. Обе сессии публикуют на один сайт asherbakov.ru (репозиторий `invisibleyobic/invisibleyobic.github.io`, ветка `main`). Правила, чтобы не мешать друг другу:

1. **Только свои папки.** В репозитории сайта трогаешь только папку новой версии осенней коробки. Старую `/ozonbox-osen/` не перезаписываешь: новая версия - новая папка, например `/ozonbox-osen-2/`. Папки `ozonbox-glavnaya-*`, `ozonbox-sos`, `ozonbox-modeli`, `ozotens-*`, `versii` не трогаешь.
2. **Общий файл одной строкой.** Оглавление `ozonbox/index.html` правят обе сессии: добавляешь только свою карточку и больше ничего.
3. **Перед пушем:** `git pull --no-rebase origin main`, потом `git push`. Никаких `--force`, rebase и amend.
4. **Не пушить подряд.** Публикация GitHub Pages идёт по очереди. Если две публикации сталкиваются, сайт может отдавать 404 весь целиком (так было 14.10.2026). Пушь одним коммитом в конце работы. После пуша подожди 1-2 минуты и проверь, что сайт открывается.
5. **Если весь сайт отдаёт 404:** не трогай файлы. Открой https://github.com/invisibleyobic/invisibleyobic.github.io/actions, на верхнем запуске «pages build and deployment» нажми Re-run, либо сделай один полезный коммит. Файл `.nojekyll` в корне уже есть, его не удаляй.

**Стиль - как у главной** (образец: https://asherbakov.ru/ozonbox-glavnaya-6/, код - `mockups/glavnaya-6/` в репозитории `invisibleyobic/ozonbox-roomtour`):

- цвета: кислотный зелёный `#46e62e`, чёрный `#0e0f0d`, белый, светло-серый `#eceeec`. Текст на зелёном - только чёрный;
- шрифты: Manrope, акцентное слово заголовка - курсив Playfair Display. Файлы шрифтов лежат в `mockups/glavnaya-6/fonts/`, подключай их локально, а не с Google;
- приёмы: бенто-плитки со скруглением 26 px, товар-вырезка с мягкой тенью, крупное слово за товаром, без серых квадратов фото;
- коробка теперь **белая**;
- корзина: подключи `shop.js` и `shop.css` из `mockups/glavnaya-6/`, тогда корзина будет общая с главной;
- тексты без медицинских обещаний (`rules/legal/no-medical-claims.md`).
