# Главная OzoneBox - версия Codex

Самостоятельный HTML/CSS/JS-макет по `prompts/codex/01-glavnaya-sorevnovanie.md`. Все файлы этой версии находятся в одной папке; приложение Next.js и предыдущие макеты не изменены.

## Направление

Основной ориентир - присланный PHLOX: крупный товарный первый экран и асимметричная сетка категорий. Использованы собственная композиция вокруг O₃, тексты и реальные фотографии OzoneBox. Чёрный, белый и согласованный кислотный зелёный `#46e62e`. Вторичный ориентир SAGE учтён в вертикальном ритме мобильной страницы.

Старые версии «Золотого яблока» не удалось проверить: запрос к Web Archive получил 403 от сетевого прокси. Макет не использует код, изображения, логотип или тексты этого магазина. Сходство с архивной или нынешней версией не проверено; юридическая экспертиза не проводилась.

## Открыть

Из корня репозитория:

```sh
python -m http.server 8081 --bind 127.0.0.1 --directory mockups/codex-glavnaya
```

Открыть локальную страницу в браузере. Все изображения и Manrope подключены локально, запросов к CDN нет. Лицензия Manrope - `vendor/Manrope-OFL.txt`.

## Что работает

- Каталог из 19 позиций, фильтры категорий и поиск по названию.
- Демонстрационная корзина: добавление, изменение количества, удаление последней единицы и пересчёт суммы.
- Переходы с плиток сразу выбирают категорию.
- Без JavaScript видны первый экран, категории, сезонная сцена и статический каталог с ценами.
- `prefers-reduced-motion` отключает движение. Анимации используют `transform` и `opacity`, без тяжёлых библиотек.

Цены - снимок данных из макета v4, вынесенный в `catalog.js`; это не актуальные цены из базы. Корзина существует только в памяти страницы. Оформление заказа и оплата не подключены; реальные заказы не создаются.

## Какие фотографии нужны

Две карточки с силуэтами - предусмотренные места под съёмку, не реальные модели и не отзывы. Нужны портреты с разрешением на использование: профиль или три четверти с видимой текстурой кожи для первой карточки; портрет с волосами для второй. Рекомендуется исходник не меньше 1600 × 1800 px, мягкий боковой свет, свободное место слева под заголовок. Желательны вырезки на прозрачном фоне для белой и чёрной подложки. Не добавлять надписи на сами фотографии.

## Проверки

В Chromium проверены 1440, 390 и 360 px: нет горизонтальной прокрутки, ошибок JavaScript или неуспешных HTTP-запросов. Проверены 19 карточек, категория волос, поиск, пустая выдача, добавление и изменение количества, сумма корзины, закрытие Escape и переход с плитки. Все изображения успешно декодированы. Отдельно проверены каталог без JavaScript и режим уменьшения движения.

`npm run lint`, `npm run build`, `npm run typecheck`, 30 тестов Vitest и `scripts/security-audit.sh` прошли. Независимое ревью выявило три замечания доступности; доступное имя корзины, контраст фокуса и объявление результатов поиска исправлены и повторно проверены рецензентом.

Снимки первого экрана: `preview-1440.png` и `preview-390.png`. Размещение на внешнем сайте не выполнялось.
