# Прототип каталога, 9 сентября 2026

Первый прототип страницы каталога OzoneBox. Сделан **до** начала Смыслокода: ни замысла `idea/`, ни чертежа `architecture/` тогда ещё не было. Это не код продукта и не макет первой версии - это источник стиля и картинок.

Раньше лежал в корне проекта под именем `ozonbox i don't know`.

## Что внутри

| Файл | Что это |
|---|---|
| `products.html` | страница каталога, 19 товаров, вёрстка целиком |
| `css/catalog.css` | стили: палитра, карточки, шапка, «орбы» на фоне |
| `js/data.js` | 19 товаров: названия, цены, описания, пути к фото |
| `js/catalog.js` | анимации на GSAP, фильтры, корзина-имитация |
| `assets/products/` | **оригиналы фото товаров** в полном размере, 19 штук |
| `assets/small/` | те же фото, ужатые. Именно они стоят в макете первой версии |
| `assets/brand/logo.svg` | логотип OzoneBox |
| `build-preview.py` | сборка всего в один самодостаточный файл |

## Про GSAP

GSAP с 2025 года бесплатен целиком, включая бывшие Club-плагины. Поэтому `js/vendor/` (25 плагинов) лежит прямо в репозитории - ничего докачивать не нужно.

Единственное, чего тут нет, - собранный `preview.html`. Не по лицензии: в нём картинки одной строкой base64, и наш сканер секретов принимает такую строку за ключ. Пересобирается одной командой, см. ниже.

## Как посмотреть прототип

Собрать однофайловый предпросмотр (картинки внутри, ничего снаружи не нужно):

    python prototypes/2026-09-09-katalog/build-preview.py

Появится `preview.html` - открывается двойным кликом, без сервера. GSAP он тянет с CDN, Club-плагины не нужны.

`products.html` напрямую откроется только с локальным `js/vendor/` на месте.
