# OzoneBox Future - проба витрины-холодильника (16.10.2026)

Запрос владельца: по референсу `design/refs/future-fridge-ref.jpg` сделать витрину - футуристичный холодильник, наверху светящийся логотип OzoneBox, внутри наши товары, по нажатию открывается карточка. Версии 16:9 и 9:16, апскейл через ByteDance (Higgsfield). Отдельная ветка-проба, главную не трогаем.

## Как сделано

- [x] Фон: Higgsfield GPT Image 2.5 по референсу - тот же стиль холодильника, вид строго спереди, полки пустые, экран сверху без надписей. Апскейл ByteDance до 4K, на сайт - webp 2560 и 1600 (16:9), 1440 и 900 (9:16).
- [x] Товары - настоящие вырезки поверх фона, не нарисованные нейросетью: на сгенерированной упаковке искажаются надписи (`design/design-system.md`, «ЗАПРЕЩЕНО», п. 7). Координаты полок - доли картинки.
- [x] Логотип - SVG владельца, белый с зелёной точкой, свечение.
- [x] Анимация по совету агента-аниматора: без библиотек (WAAPI), экран разгорается, двери распахиваются, товары встают каскадом сверху вниз, около 2,2 с. Нажатие во время заставки - сразу к концу. С `prefers-reduced-motion` - без дверей и мерцания.
- [x] Агент-контролёр проверил скриншоты и код. Исправлено: белый текст в карточке на белом фоне, посадка товаров на телефоне, размеры, прозрачность дверей, подсказка исчезает, подписи у крайних товаров, доступность с клавиатуры.
- [x] Опубликовано: https://asherbakov.ru/ozonbox-future/

## Ограничения

- Крем точечного действия не на полке: его фото - баннер с надписями, чистую вырезку не сделать. Наборы - фото коробок, вырезок нет.
- Стеклянные двери в анимации - HTML поверх картинки; открытые двери на самой картинке нарисованы отдельно.
- Независимого ревью в отдельной сессии не было.
