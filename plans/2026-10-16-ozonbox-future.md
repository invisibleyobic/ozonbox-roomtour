# OzoneBox Future - проба витрины-холодильника (16.10.2026)

Запрос владельца: по референсу `design/refs/future-fridge-ref.jpg` сделать витрину - футуристичный холодильник, наверху светящийся логотип OzoneBox, внутри наши товары, по нажатию открывается карточка. Версии 16:9 и 9:16, апскейл через ByteDance (Higgsfield). Отдельная ветка-проба, главную не трогаем.

## Как сделано

- [x] Фон: Higgsfield GPT Image 2.5 по референсу - тот же стиль холодильника, вид строго спереди, полки пустые, экран сверху без надписей. Апскейл ByteDance до 4K, на сайт - webp 2560 и 1600 (16:9), 1440 и 900 (9:16).
- [x] Товары - настоящие вырезки поверх фона, не нарисованные нейросетью: на сгенерированной упаковке искажаются надписи (`design/design-system.md`, «ЗАПРЕЩЕНО», п. 7). Координаты полок - доли картинки.
- [x] Логотип - SVG владельца, белый с зелёной точкой, свечение.
- [x] Анимация по совету агента-аниматора: без библиотек (WAAPI), экран разгорается, двери распахиваются, товары встают каскадом сверху вниз, около 2,2 с. Нажатие во время заставки - сразу к концу. С `prefers-reduced-motion` - без дверей и мерцания.
- [x] Агент-контролёр проверил скриншоты и код. Исправлено: белый текст в карточке на белом фоне, посадка товаров на телефоне, размеры, прозрачность дверей, подсказка исчезает, подписи у крайних товаров, доступность с клавиатуры.
- [x] Опубликовано: https://asherbakov.ru/ozonbox-future/

## Ограничения

- Крем точечного действия не на полке: его фото - баннер с надписями, чистую вырезку не сделать. Наборы - фото коробок, вырезок нет.
- Стеклянные двери в анимации - HTML поверх картинки; открытые двери на самой картинке нарисованы отдельно.
- Независимого ревью в отдельной сессии не было.

- [x] Без повторов: на полках 8 разных товаров, по разделам - «Волосы», «Лицо», «Точечно», «Масло и тело». Таблички на полках.
- [x] Наборы на полки не ставим: на их фото наклейки и надписи (OZONE BOX #3, SOS, банты), вырезки грязные и перегружают витрину. Вместо них на нижней панели - «Наборы и боксы», ведёт в каталог главной 11 сразу на наборы (`#sets`).
- [x] Карточка товара: фото показывается целиком (`object-fit: contain`), наборы и крем точечного действия больше не обрезаются. Правка и в главной 11, и в SOS бокс 2.
- [x] Кнопки Ozon и WB: поиск по площадке убран, ведут в магазин продавца, пока нет ссылок на карточки (вопрос 1.19).
- [ ] Ссылки один в один на карточки: сервер не открывает Ozon и WB. Нужны ссылки от владельца или Рафаэля либо доступ через браузер владельца.

## Все 19 позиций (16.10.2026, вечер)

- [x] Владелец: витрина стала пустой, нужны все 19 позиций каталога (как в «Хитах продаж» главной 11). Теперь на полках все 19, без повторов.
- [x] Наборы - чистые рендеры с прозрачным фоном из Google Drive (`OzoneBox 2026 site materials / Ozone_Product / 02 Наборы / <набор> / 01 Фото и изображения товара`, файлы `web-*.png`), белый подиум срезан. «Супер сет» с Drive = наш «Супер комбо». «Сет для лица» собран из рендеров «Безупречно чистая кожа» и «Стоп акне», «Супер трио» и «Супер дуэт» - из вырезок их товаров (у дуэта бант).
- [x] Крем точечного действия = «Крем SOS 30%» (папка `01 Товары / 12 Крем SOS`).
- [x] Товары расставляются по ширине упаковки, по 4-5 на полке; на телефоне 5 полок, таблички разделов только на компьютере.
- Имена внутренних подпапок на Drive испорчены кодировкой (имена из Windows в CP866 прочитаны как CP1251): «01 Фото и изображения товара», «02 Карточки и инфографика», «03 Рекламные материалы», файл «Состав набора.txt». Переименовать или убрать промежуточную папку - решение владельца, через коннектор Drive не трогал.

## OzoneBox Future 3 - на вершине скалы (16.10.2026)

- [x] Владелец: холодильник не должен висеть в воздухе, пусть стоит на возвышенности. Предложил вулкан, по которому скатываются прыщи. Отказался от этой идеи: картинка выходит неприятной, и это близко к обещанию «избавим от акне» (`rules/legal/no-medical-claims.md`). Сделана вершина скалы над облаками.
- [x] `mockups/future-3/` → https://asherbakov.ru/ozonbox-future-3/. Фон - горы над облаками (Higgsfield, 16:9 и 9:16), скала с плоской вершиной - отдельная картинка с прозрачностью, стоит за холодильником, ножки на середине площадки, под ними тень.
- [x] Сцена уменьшена до 80% высоты экрана, чтобы скала была видна. Облака плывут сзади и спереди, холодильник не качается.
