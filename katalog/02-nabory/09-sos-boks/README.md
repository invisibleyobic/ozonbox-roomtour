- [ ] Объём или вес каждого средства (у наборов - каждого предмета)
- [ ] Полный состав (INCI)
- [ ] Способ применения
- [ ] Противопоказания и возраст
- [ ] Срок и условия хранения
- [ ] Документ соответствия (декларация или СГР) - номер
- [ ] Штрихкод (EAN) и маркировка «Честный знак» (вопрос 1.10 в `ВОПРОСЫ.md`)

- [ ] Видео для сцены (по желанию)
- [ ] Ссылки на карточки Ozon и Wildberries
- [ ] Описание для покупателя без медицинских обещаний (2-3 абзаца)
