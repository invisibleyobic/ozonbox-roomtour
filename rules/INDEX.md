# INDEX.md - маршрутизатор правил

> Источник: github.com/artemiimillier/rules (MIT, коммит 0f95834 от 27.08.2026),
> поставлено в OzoneBox 13.10.2026 по слову владельца. При конфликте с
> `architecture/00-правила-проекта.md` главнее он (порядок источников - в `CLAUDE.md`).

Это входная точка папки `rules/`. Агент читает её первой и по таблице ниже
понимает, какие регламенты обязан открыть ДО начала работы. Правило простое:
**не прочитал нужный регламент - задачу не начинал.**

## Таблица маршрутов

| Что за задача | Что читать обязательно |
|---|---|
| Лендинг, рекламный пост, любой публичный текст | `legal/no-medical-claims.md`, `legal/no-education.md`, `legal/anglicisms.md`, `legal/no-guarantees.md`, `texts/style.md` |
| Публичная оферта, договор, политика возврата, чек | `legal/offer-checklist.md`, `legal/no-education.md` (раздел «Документы») |
| Письмо рассылки, тексты бота, личный кабинет | `legal/no-education.md` (чек-лист точек касания), `texts/style.md` |
| Карточка товара, описание средства, каталог (OzoneBox) | `legal/no-medical-claims.md`, `legal/anglicisms.md`, `legal/no-guarantees.md`, `texts/style.md` |
| Дизайн, вёрстка, UI, новые компоненты | `design/brand.md` |
| Коммит, деплой, скрипты, работа в репозитории | `code/workflow.md` |
| SEO-метаданные, schema.org, sitemap | `legal/no-education.md` (технические следы), `legal/anglicisms.md` |

## Как пользоваться

1. Перед задачей открываешь эту таблицу, находишь свой тип задачи, читаешь
   указанные файлы. Все перечисленные, а не первый попавшийся.
2. Перед публикацией любого текста - греп по запрещённым словам из словарей
   (`legal/no-education.md`, `legal/anglicisms.md`). Нашёл - переписал, потом
   показал человеку.
3. Если задача не попадает ни в одну строку таблицы или правила противоречат
   друг другу - спроси человека. Не выдумывай своё правило.
4. Новое правило появляется так: человек сказал «не так, потому что...» -
   оформи это в подходящий файл по канону «Правило → Почему → Как применять»
   и допиши строку в эту таблицу, если появился новый тип задач.

## Структура папки

```
rules/
├── INDEX.md              ← этот файл
├── legal/                ← юридические регламенты (РФ, онлайн-бизнес)
│   ├── no-education.md      ← нет лицензии - не используем лексику образования
│   ├── anglicisms.md        ← ФЗ-53 о госязыке: что заменять, что оставлять
│   ├── no-guarantees.md     ← запрет гарантий результата и дохода
│   └── offer-checklist.md   ← что обязано быть в публичной оферте
├── texts/
│   └── style.md          ← тон, стоп-слова, маркеры машинного текста
├── design/
│   └── brand.md          ← палитра, шрифты, сетка, правила компонентов
└── code/
    └── workflow.md       ← коммиты, секреты, деплой, временные файлы
```
