# Чертёж OzoneBox

Claude пишет код только по этому чертежу. Если задача противоречит чертежу - остановиться и спросить. Замысел, на который опирается чертёж, лежит в `idea/`, начинать с `idea/pitch.md`.

## Оглавление

- `00-правила-проекта.md` - нерушимые правила: всегда / спроси / запрещено
- `01-что-строим.md` - продукт простыми словами и границы первой версии
- `02-сущности.md` - общий словарь главных вещей продукта и связей
- `03-база-данных.md` - таблицы, индексы, правила целостности, миграции
- `schema.prisma` - готовая схема базы, первая миграция на эфире 4
- `04-потоки-данных.md` - что человек видит сразу, что уходит в фон
- `05-стек.md` - технологии и почему именно они
- `06-внешние-сервисы.md` - оплата, уведомления, хранилище, MCP, дневные потолки
- `07-безопасность.md` - персональные данные, защита, расходы, роли
- `08-структура-кода.md` - модули, папки, переходники, карта владения окнами
- `09-риски.md` - премортем архитектуры
- `10-план-реализации.md` - план по неделям и промпт на эфир 4
